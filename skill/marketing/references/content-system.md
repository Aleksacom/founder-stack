# Content system — pillars, repurposing, platform formats, calendar

## Pillars (5–7)

A pillar = intersection of (audience pain you solve) × (topic you can speak on with proof). Not generic categories ("tips", "motivation") — named territories:

- Good: "Making friends after relocation", "Why interest-matching fails", "Behind the matching engine"
- Bad: "Community", "Product updates", "Inspiration"

Pillar mix rule: ~40% pain/problem content, ~30% proof/result content, ~20% mechanism/how-it-works, ~10% personal/founder story. Each pillar gets 10 subtopics (specific angles, each answerable in one post).

## Repurposing: 1 long → 20 short

From one long-form piece (blog post, video, podcast, deep thread) extract:
- 5 hooks (strongest claims, reframed via hook-formulas.md families)
- 5 one-liners (quotable single sentences, standalone)
- 5 mini-stories (anecdotes/examples inside the piece, retold in 3–5 lines)
- 3 contrarian takes (where the piece disagrees with common advice)
- 2 data points (stats framed as PROOF hooks)

## Platform formats (only for platforms in context.md)

| Platform | Format | Length | Notes |
|----------|--------|--------|-------|
| X/Twitter | thread | hook tweet + 5–8 tweets | hook tweet must stand alone; last tweet = CTA |
| Instagram | carousel | 6–10 slides | slide 1 = hook only; one idea per slide; last = CTA |
| TikTok/Reels/Shorts | script | 30–60s | spoken hook ≤2s; pattern-interrupt at ~15s; caption ≠ script |
| LinkedIn | text post | 150–300 words | line 1 = hook (shown before "see more"); white space; no links in post body |
| YouTube | title + outline | — | title = ad headline format from hook-formulas.md |
| Email/newsletter | subject + body | subject ≤6 words | subject = curiosity family; body = one proof-story |

## Proof-loop injection

≥50% of calendar posts must carry a proof element (stat, screenshot, case study, result, user quote). Mark each calendar row `proof: yes/no` and check the ratio before delivering. Proof sources: marketing/proof.md if exists, else context.md facts.

## 30-day calendar format

Markdown table, one row per day:

| Day | Date | Pillar | Subtopic | Platform | Format | Hook (draft) | Proof? |
|-----|------|--------|----------|----------|--------|--------------|--------|

Rules: rotate pillars (no pillar 2 days straight); post frequency per platform from user's actual capacity (ASK — don't assume daily); every row's hook drafted (not "TBD"); batch-friendly ordering note at the end (which rows to produce in one sitting).
